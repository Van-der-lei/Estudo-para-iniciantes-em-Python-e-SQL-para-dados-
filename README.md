# Estudo-para-iniciantes-em-Python-e-SQL-para-dados
#### 📚 Fontes e Materiais de Referência

Este repositório foi estruturado com base em **34 fontes de estudo e consulta** especializadas em **Python e SQL para Análise e Engenharia de Dados**. O acervo engloba desde documentações oficiais até scripts práticos de mercado:

### 1. 📖 Documentações Oficiais e Guias Base
* **Documentação Oficial do Python 3**: Referência técnica da linguagem e de sua biblioteca padrão.
* **Documentação do `sqlite3`**: Interface oficial DB-API 2.0 para integração e manipulação de banco de dados nativo em Python.
* **Khan Academy & Metabase**: Guias fundamentais de sintaxe SQL e *Cheat Sheets* de comandos.

### 2. 🗺️ Roadmaps e Modelagem de Dados
* **Roadmaps de SQL & Data Engineering**: Trilhas de aprendizado do nível básico ao avançado (cobrindo CTEs, *Window Functions* e agregações complexas).
* **Normalização de Banco de Dados**: Teoria e regras formais de modelagem relacional (DCC UChile).
* **Projetos e Repositórios de Prática**: Esquemas relacionais e bases de dados para exercícios práticos de consulta.

### 3. ⚡ Otimização, Performance e Administração (DBA)
* **Scripts de Performance Tuning**: Scripts essenciais para diagnóstico e otimização no SQL Server Management Studio (Fabridata).
* **100 Scripts de DBA**: Rotinas práticas para análise de índices, locks e manutenção de SGBDs (The SQL Times).
* **Boas Práticas de Consulta**: Guias de otimização de performance e legibilidade de código SQL (Hashtag Treinamentos e DIO).

### 4. 🐍 Python, Programação Orientada a Objetos e Integração
* **Python Orientado a Objetos (POO)**: Estruturação de classes, métodos, abstração e boas práticas de arquitetura de software.
* **Integração Python + SQL**: Conexão entre scripts Python e SGBDs, execução de queries, prevenção contra SQL Injection e manipulação de dados.
* **Cursos e Masterclasses**: Conteúdos completos de capacitação do zero ao avançado (Simplilearn, Coursera, entre outros).
